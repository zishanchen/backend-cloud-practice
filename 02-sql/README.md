# SQL Practice

This folder contains SQL exercises and schema design practice.

## Files

- `setup.sql` — creates sample data for SQL practice
- `select-basics.sql` — practices SELECT, WHERE, ORDER BY, and LIMIT
- `task-system-schema.sql` — defines users, tasks, status_history, and audit_logs

- LIMIT
- CREATE TABLE
- PRIMARY KEY
- FOREIGN KEY
